# Security Policy

TelosZero Core is private during bootstrap and should not yet be treated as a
production release channel.

## Reporting A Vulnerability

Report suspected vulnerabilities privately. During bootstrap, use GitHub private
repository access to contact maintainers directly or email `devs@telos.net`.

Do not open public issues for suspected vulnerabilities after the repository is
made public.

## Supported Versions

No TelosZero Core production version is currently supported.

Support begins only after maintainers publish:

- a signed production release
- checksums and artifact provenance
- operator upgrade guidance
- a support window for that release line

## Disclosure

Maintainers should coordinate fixes privately, prepare patched artifacts, and
publish disclosure notes only after affected operators have a safe upgrade path.
