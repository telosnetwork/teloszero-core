# Support

TelosZero Core is in private bootstrap. There is no production support channel
until the first signed release is published.

## Bootstrap Support

Use private GitHub issues or TelosNetwork maintainer channels for:

- build failures
- packaging issues
- CI runner setup
- release process questions
- upstream patch triage

## Operator Support

Operator support begins after a release is explicitly marked production-ready.
Production release notes must include:

- supported operating systems
- package names and checksums
- upgrade steps
- rollback steps
- known incompatibilities
- test coverage summary
