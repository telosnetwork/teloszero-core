## Telos Genesis Files

This directory contains the public Telos network genesis files used when
starting a node from genesis.

| Network | Genesis file | Chain ID |
| --- | --- | --- |
| Telos Mainnet | `telos_mainnet_genesis.json` | `4667b205c6838ef70ff7988f6e8257e8be0e1284a2f59699054a018f743b1d11` |
| Telos Testnet | `telos_testnet_genesis.json` | `1eaa0824707c8c16bd25145493bf062aecddfeb56c736f6ba6397f3195f33c9f` |

The chain ID files are provided as convenient reference values for
configuration checks and node verification. The canonical chain ID is computed
from the corresponding genesis state.
